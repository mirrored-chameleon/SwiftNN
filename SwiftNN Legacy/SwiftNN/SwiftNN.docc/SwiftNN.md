# ``SwiftNN``

SwiftNN is an open-source, modular neural network framework written in Swift, designed for building and training neural networks entirely in Swift without using other programming languages.

## Overview

This project uses Surge, a high-performance Swift library for numerical and matrix operations.
https://github.com/Jounce/Surge

## Topics

### SwiftNN

- SwiftNN is designed to be as lightweight as possible, and easy to intergrate with ML expiriments and projects. It features a modular 'Talent' and 'Network' system to keep things as modular as possible. Talents consist of an encoder and decoder for different data types, and each network can contain any talent, so each model can be used with different talents for it. Of course, you do not need to make your model modular, it is just in place if you would like too. I hope to build a community around this project so that people can share models, share extensions and adopt eachother's ideas and snippets of code in your own projects. Of course, you do not need to share, it is just a guideline if you would like to contribute to this project.
