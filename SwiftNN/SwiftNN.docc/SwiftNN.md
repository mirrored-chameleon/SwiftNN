# ``SwiftNN``

SwiftNN is an open source, modular neural network framework in swift so that you can create custom neural nets purely in swift with no porting from other languages.

## Overview

This project uses Surge, a high-performance Swift library for numerical and matrix operations.
https://github.com/Jounce/Surge
